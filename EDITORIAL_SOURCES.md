## Experience basis

Owner's installation and remote-access observations, 22–25 October 2026, including the explicit editorial clarification of 25 October: the native Ubuntu desktop was reached by physical console; the remote native desktop was not completed. NVIDIA Sync Dashboard is a management interface. Olares Web Desktop is a web workspace, while the Windows VM console/CRD shows the guest OS.

The separate owner/guest delegation paths were reviewed in documentation, not exercised as a new multi-user test. LarePass multiple IDs and multiple client logins must not be represented as an automatically unified identity across every server.

No new hardware or software test was run for this revision.
