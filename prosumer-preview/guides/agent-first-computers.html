PROSUMER / DESIGN PRINCIPLE · 26 OCT 2026

AGENT-FIRST.
STILL HUMAN-OWNED.

The next personal AI computer should be understandable to two operators: its owner, and the AI assistant that owner already uses.

Most “AI PCs” answer one question: can this computer run AI? A new question matters just as much: can my AI operate this computer for me — safely, usefully, and without turning me into its full-time administrator?

Why this matters

AI made it easier to ask for a tool, a prototype or an answer. But setting up the computer to produce one can still require a second career in drivers, Docker, permissions and recovery procedures.

I want to make tools. I don't want to become a tool-maintenance department.

That is the difference between an impressive box and a genuinely useful personal AI computer.

01Definition

Agent-friendly is good.
Agent-first goes further.

Both are useful. They solve different problems.

TODAY'S MOST COMMON APPROACH

AGENT-FRIENDLY

The manual is easy to parse. The computer has SSH, APIs, scripts and helpful error messages.

An AI assistant can work with the machine if someone has already assembled the right access and tools.

THE NEXT PRODUCT QUESTION

AGENT-FIRST

The machine is designed from the outset for a second, authorised operator.

It can explain its state, expose limited actions, safely request owner decisions and provide a recovery route. The owner remains the principal.

An agent-first computer is not a computer that AI owns. It is a computer deliberately designed to be operated by AI on its owner's behalf.

02Design

The two-operator contract.

Six promises a manufacturer could make — and a buyer could actually test.

01

DISCOVER

Tell the agent what hardware, software and capabilities exist, without requiring a forensic scavenger hunt.

02

ONBOARD

Get from first boot to a task the owner recognises as useful, with clear human approval where needed.

03

OPERATE

Offer understandable, bounded ways to install, run and inspect applications — not unrestricted root as the default.

04

RECOVER

Expose what broke, what was last healthy, what can be retried and when a human must intervene.

05

DELEGATE

Grant a person or agent one capability, for one purpose, under scope and expiry. Make revocation real.

06

ACCOUNT

Show what the agent did, what changed, whether the owner's goal was met and how much intervention was required.

These are proposed design criteria, not evidence that any current device satisfies all six.

03Interactive

What would this change on a Tuesday?

Choose a familiar situation. The right-hand side is the product behaviour we'd want — not a feature claim about a shipping machine.

WITHOUT AGENT-FIRST DESIGN

Fourteen tabs. Three drivers. One evening gone.

You wanted to analyse a folder of documents locally. You're instead figuring out drivers, downloads, ports and which command ran last.

WHAT AN AGENT-FIRST PC SHOULD ENABLE

From unboxing to a useful document answer.

Your approved assistant reads device capabilities, installs a supported workflow, asks for any sensitive decision, then shows the result and what it changed.

PASS CONDITION / The user gets a correct, usable result — without hidden intervention, surprise access or unexplained system changes.
04Ownership

Power without blanket permission.

An assistant should be able to help. It should not need the keys to everything.

An admin login or a functioning API tells us what a process can access. It does not tell us what that agent was authorised to do for this owner, for this task, at this moment.

EXAMPLE / READ

Inspect GPU state

Allow read-only diagnostics for this session. Preserve evidence of what was inspected.

EXAMPLE / CHANGE

Install a model

Ask permission to alter the machine, show the scope of changes and provide a rollback plan.

EXAMPLE / SHARE

Give access to an endpoint

Limit a collaborator to one application; define expiry and access boundaries.

EXAMPLE / REVOKE

Stop the delegation

Prove that an expired or revoked permission no longer works — without destroying the owner's own access.

Human-owned is non-negotiable. Being agent-first does not mean agents decide the purpose of the computer, override the owner or claim that a successful SSH session proves safe delegation.

05Evidence

Spark gave us a partial glimpse.

Useful assisted operation, not a completed agent-first certification.

During an October 2026 NVIDIA DGX Spark field study, the owner handled physical setup, firmware, identity activation and approvals. An AI operator helped inspect actual system state, diagnose a GPU/driver failure chain, carry out recovery steps and verify working application outputs.

That division of labour matters. So do its limits: there was no controlled reduction-in-owner-time measurement, no unattended first boot, no cross-agent comparison, and no third-party delegated-access/revocation result.

A machine + documentation + an AI operator + human help is the system that was observed. Do not pretend it is a score for the machine alone.

06Method

How Prosumer should evaluate it.

The next benchmark is not a single synthetic command. It is a real task with an owner, a boundary and a verified result.

TASK

First useful result

Can a new owner complete a meaningful local AI task, and how long does it take from a defined starting point?

INTERVENTION

How often did a human step in?

Record physical actions, approvals, debugging, surprises and steps the assistant could not perform.

PORTABILITY

Can the result travel?

Repeat the task across appropriate agents and devices. Disclose prior setup, network tools and hidden dependencies.

BOUNDARIES

Was the scope respected?

Confirm the allowed action succeeded, forbidden actions failed, and permissions could be revoked.

A green PASS badge is not the product. A useful result — with transparent effort and retained human control — is the product.

07Manifesto

Design for what people want to make.

Not just the resources computers can theoretically consume.

THE NEXT GREAT AI PC SHOULD MAKE THE OWNER MORE CAPABLE, NOT MORE RESPONSIBLE FOR KEEPING THE INFRASTRUCTURE ALIVE.

Better components matter. But the larger product opportunity is a machine that explains itself, accepts bounded help, recovers intelligibly and gives its owner more room to create.
