## AuthorityClaw/MANDATE — синтетический dry-run, PASS

Это минимальная тестовая модель полномочий по указанным пользователем понятиям, а не проверка соответствия не предоставленной спецификации или интеграция с реальным AuthorityClaw. Только вымышленные личности и ресурсы; фиксированное тестовое время `2026-10-22T12:00:00Z`. Никакие действия из плана не выполнялись.

Модель составила план по шести кандидатам. Независимый детерминированный JavaScript-проверяющий прочитал исходный fixture, а не утверждения модели, и проверил principal, capacity, привязку mandate, scope, интервал действия и revocation.

| Кандидат | Независимый результат | Причина |
|---|---|---|
| A1 | ALLOW | Все условия выполнены |
| A2 | DENY | Ресурс вне scope |
| A3 | DENY | Mandate истёк |
| A4 | DENY | Mandate отозван |
| A5 | DENY | Principal не совпадает; нарушена привязка |
| A6 | DENY | Capacity не предоставлена; нарушена привязка |

Решения модели совпали с независимыми во всех 6 случаях. Проверяющий не является production security boundary: нет настоящей аутентификации, подписей, внешнего реестра отзыва или атомарной проверки перед исполнением. Это воспроизводимый тест логики на доверенном синтетическом fixture.
