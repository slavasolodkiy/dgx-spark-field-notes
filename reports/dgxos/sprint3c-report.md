## Проверки после загрузки — BLOCKED

В первые минуты SSH устанавливал TCP-соединение с прежним IP, но удалённая сторона закрывала его до обмена ключами:

```text

Connection closed by [SPARK_LAN_IP] port 22
```

С 09:46:58 сообщение изменилось на `banner exchange: Connection to UNKNOWN port -1: Connection refused`. Проверка `ssh -G` подтвердила прежние адрес [SPARK_LAN_IP], порт 22 и пользователя slava без ProxyCommand. Ping в 09:48 отвечал за 1 ms. Последняя SSH-попытка в **09:49:29 BST**, через примерно **10 минут** после команды reboot, также неуспешна. Причина недоступности SSH не установлена; отказ в подключении не доказывает успешную загрузку нового ядра.

Новый boot ID получить не удалось. Поэтому завершение перезагрузки, `nvidia-smi`, CUDA initialization, kernel в Docker и GPU inference **не подтверждены**. Повтор Xid 119 после загрузки также не установлен: нового журнала нет. Точное место остановки без доступа к консоли неизвестно.

Для CUDA kernel планировалось повторно использовать уже имеющийся бинарник Sprint 2 и закэшированный CUDA-контейнер, без новых загрузок и изменений runtime.
